# Original windshield mud and wipers

`web/client/native-mud-mask.js` reconstructs the original mud coverage from the authorized native `CarGlass` shader, `sharedassets1.assets` Shader path ID 198. Its D3D11 pixel bytecode SHA-256 is `55b9f123bfa9256ef1796f9f85268dc3d2fbbbd97be7fa395ce54b8981cfb8e3`. Shader tokens were decoded using [Microsoft's tokenized program format](https://github.com/microsoft/DirectX-Headers/blob/main/include/directx/D3D12TokenizedProgramFormat.hpp). Ignored intermediate evidence is under `local/web-assets/audit/CarGlass-{2.dxbc,pixel.dxbc.txt}`, `native-mud-mask.glsl` and `native-mud-wipers.json`.

The original covers the actual `BodyVisual/windscreen_ok` mesh, not a small overlay plane or bitmap. `WindshieldMud.ResolveWindscreen` (RVA `0x514B20`) copies the mesh bounds into `_MudBoundsMin/Max`, sets opacity 1 and mud color `[0.3,0.2,0.11]`. The vertex shader passes original object position; pixel coverage normalizes **object XY** by those bounds. Because browser geometry reflects X, normalized native UV is `[1-browserU,browserV]`, where browserV comes from mesh Y, not Z. The source procedural noise scale is 3.5. Original deposits in all three stages add 0.5 mud with a 3-second trigger cooldown; mud is clamped to 0–1.

The prior browser mask thresholded a fractal noise field and left the centre view sparsely covered. Native coverage instead takes the maximum of three irregular ellipse masks. It remaps normalized UV as `(uv-[0.23,0.29])/[0.67,0.62]`, then uses centres `[0.48,0.44]`, `[0.30,0.30]` and `[0.68,0.42]`; primary radius is `0.78*amount`, secondary radii `0.3276*amount`. Distances scale the two components by `[0.7,0.48]`, with 0.035 feather width, original value-noise warp and radius perturbation. At amount 0.5, native normalized UV `[0.5516,0.5628]` is fully occluded. A 100×100 uniform UV reference grid gives mean coverage approximately 58.1% at 0.5, 94.7% at 0.8 and 99.9% at 1. These are sampled normalized rectangles, not screenshot pixel measurements. Native alpha is `mix(glassAlpha,1,mask*opacity)`.

The helper exports `NATIVE_MUD_GLSL` and a CPU `nativeMudMask(uv,amount,noiseScale)` reference. GLSL also accepts `nativeMudMask(objectXY,boundsMinXY,boundsMaxXY,amount,noiseScale)`. It ports coverage only; original glass lighting and wiper-sector selection are separate. The focused tests use 26 expected values independently evaluated from decoded native pixel instructions 1678–4303, rather than values generated by the helper. Maximum difference is below 0.00000622 with seven-significant-digit decoded constants. All three focused tests pass; runtime GPU and screenshot verification remain the renderer owner's responsibility.

`WindshieldWipers` uses execution order 310. Native `Setup` (`0x516B90`), `LateUpdate` (`0x516160`) and `Step` (`0x517440`) sweep 0–95 degrees around the glass normal, **premultiplying** the original rest rotation. Each one-way stroke lasts 0.45 seconds; parameter `t` advances linearly and the displayed angle uses `t*t*(3-2*t)`. Releasing wipe finishes the current outward/return cycle and stops at parked `t=0`, rather than snapping to rest. For the original unreadable-glass fallback, the normalized BodyVisual-local browser axis is `[0,0.814408936,0.580291379]`, with angle **negative** after the X reflection: `AngleAxis(-95*smoothstep(t),axis)*rest`.

The blade's inner 0.18 fraction of reach does not touch glass. `PushShader` (`0x5165E0`) sends world-space pivots, rest directions, glass axis and sweep vectors `(fromAngle,toAngle,innerRadius,fullSweepAngle)`. The fourth component is always the full signed 95-degree sweep in radians, not a boolean and not cleared at park. `_MudAhead` is the cached amount at this stroke's start while running; when parked it equals displayed mud. Effective coverage amount is `mix(display,mix(max(display,ahead),display,currentSectorUnion),fullSweepSectorUnion)`: outside the full wiper sweep it uses displayed mud, inside the full sweep it retains the prior amount until the blade passes. Both sector unions include the original radial/angle feathering. At park, equal ahead/display amounts make the whole glass use current displayed mud.

`WindshieldMud.Update` (`0x515190`) clears linearly at `dt/2` while held and presents the amount using `Mathf.SmoothDamp` with 0.15-second smoothing. `LateUpdate` (`0x513D00`) spins the knob around native local Z at 420 degrees/second; reflection reverses the browser Z sign. The source shader has no mud bitmap.
